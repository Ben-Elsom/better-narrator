# Better Narrator

A macOS menu-bar app that reads Claude replies aloud with a local Kokoro voice (Heart by default, Bella as an option), with proper playback controls.

## Planned features

- **Copy, then Read:** copy a reply in Claude and a Read button appears on the Touch Bar for about 10 seconds. A "Read latest" option loads the newest reply from the Claude window.
- **Player window:** the reply text with a blue highlight on the current word, auto-follow while reading, and a Jump to live button.
- **Start when ready:** the Start button waits until enough audio has been generated to play without stuttering.
- **Touch Bar controls:** −15s, Start/Play/Pause, +15s and Dismiss (press twice to confirm).
- **⏯ key and Now Playing** control the reading instead of opening Apple Music.
- **Speed buttons:** 1×, 1.25×, 1.5×, 2×.
- **Code blocks** are skipped with a short "code snippet" announcement.

Everything runs locally and offline. Kokoro is free and open source (Apache 2.0).
